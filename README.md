## Projetos em destaque

### 🤖 [PRIYA — Assistente pessoal com IA local](https://github.com/lazaro3308/Local-IA--PRIYA)

Assistente desktop para Windows, desenvolvida em Python e integrada ao Ollama para executar modelos de linguagem localmente.

- Integração com o modelo Qwen 2.5 7B.
- Histórico de conversas e memórias explícitas com SQLite.
- Interface gráfica com PySide6.
- Ferramentas para arquivos, aplicativos e janelas do Windows.
- Recursos opcionais de voz com Vosk e Piper.
- Ações sensíveis protegidas por confirmação.

**Tecnologias:** Python · Ollama · Qwen 2.5 · SQLite · PySide6 · Vosk · Piper

### 🧩 [G-TECH — Sistema de Gestão de Serviços e Chamados](https://github.com/lazaro3308/TCC-G-TECH)

Projeto acadêmico de conclusão de curso voltado à abertura, gestão e acompanhamento de chamados de suporte técnico. Possui uma área para clientes e um painel para a equipe técnica, conectados a uma API e a um banco de dados.

- Cadastro e autenticação de clientes.
- Abertura e acompanhamento de chamados.
- Painel técnico para consulta e atualização dos atendimentos.
- API com controle de acesso e validação de dados.
- Persistência em banco de dados relacional.

**Tecnologias:** React · JavaScript · Vite · Node.js · Express · MySQL

### 🛠️ [SmartDesk](https://github.com/lazaro3308/SmartDesk)

Projeto de classificação de chamados técnicos com apoio de inteligência artificial, explorando processamento de linguagem natural.

**Tecnologias:** PHP · Hugging Face · BART-large-MNLI

### 📚 [Biblioteca Admin](https://github.com/lazaro3308/Biblioteca-Adimin)

Sistema para gerenciamento de biblioteca, com recursos administrativos para organizar livros e empréstimos.

**Tecnologias:** React · JavaScript

### 🏥 [HealthHub](https://github.com/lazaro3308/HealthHub)

Projeto web com foco em uma interface para informações e recursos relacionados à saúde.

**Tecnologias:** HTML · CSS · JavaScript
